# Credit Scoring with Explainable AI

Проект системы кредитного скоринга, которая оценивает риск клиента с помощью машинного обучения и формирует объяснение принятого решения.

В качестве основной модели используется XGBoost. Для интерпретации отдельных предсказаний применяется SHAP, а для формирования понятного текстового объяснения результатов используется GigaChat.

## Возможности

- обработка данных кредитной истории;
- предобработка и обработка пропущенных значений;
- обучение моделей машинного обучения;
- оценка качества моделей;
- подбор порога классификации;
- предсказание кредитного риска для нового клиента;
- объяснение предсказания с помощью SHAP;
- генерация текстового объяснения с помощью GigaChat;
- REST API на FastAPI;
- веб-интерфейс на Streamlit.

## Датасет

В проекте используется датасет HELOC (Home Equity Line of Credit).

Целевая переменная `RiskPerformance` преобразуется следующим образом:

```text
Good - 0
Bad - 1
Таким образом, модель оценивает вероятность принадлежности клиента к классу Bad.

Логика принятия решения

Модель возвращает вероятность класса Bad.

Для классификации используется заранее подобранный порог:

probability > threshold → Bad
probability <= threshold → Good

Порог сохраняется отдельно от модели в xgb_threshold.pkl.

Объяснение предсказаний

Для каждого клиента рассчитываются SHAP-значения, позволяющие определить, какие признаки оказали наибольшее влияние на предсказание модели.

Для каждого из наиболее значимых признаков отображаются:

название признака;
его значение;
SHAP-значение;
направление влияния на риск.

После этого информация о предсказании и основных факторах передаётся в GigaChat, который формирует текстовое объяснение решения модели.

Описание основных файлов

train.py — основной скрипт обучения моделей и сохранения результатов.

src/data.py — загрузка и подготовка исходных данных.

src/preprocessing.py — предварительная обработка признаков и работа с пропущенными значениями.

src/models.py — определение и работа с моделями машинного обучения.

src/evaluation.py — оценка качества моделей и сравнение результатов.

src/explainability.py — расчёт SHAP и подготовка данных для объяснения предсказания.

api.py — REST API на FastAPI.

app.py — пользовательский веб-интерфейс на Streamlit.

artifacts/ — сохранённые модели и другие артефакты, необходимые для выполнения предсказаний.

Запуск проекта
1. Клонирование репозитория
git clone https://github.com/YOUR_USERNAME/credit-scoring.git
cd credit-scoring
2. Создание виртуального окружения

Windows:

python -m venv .venv
.venv\Scripts\activate

Linux / macOS:

python -m venv .venv
source .venv/bin/activate
3. Установка зависимостей
pip install -r requirements.txt
4. Настройка GigaChat

Создайте файл .env в корне проекта:

GIGACHAT_API_KEY=your_api_key

Файл .env не должен добавляться в Git.

5. Запуск FastAPI
uvicorn api:app --reload

После запуска API будет доступно по адресу:

http://127.0.0.1:8000

Документация Swagger:

http://127.0.0.1:8000/docs
6. Запуск Streamlit

В отдельном терминале:

streamlit run app.py

После запуска Streamlit покажет адрес веб-приложения.

API

Основной endpoint:

POST /predict

Endpoint принимает данные одного клиента и возвращает:

предсказание Good или Bad;
вероятность класса Bad;
используемый порог классификации;
наиболее значимые SHAP-факторы;
текстовое объяснение от GigaChat.

Также доступны:

GET /
GET /health
Результат

Веб-интерфейс позволяет ввести характеристики клиента и получить:

вероятность кредитного риска;
итоговое решение модели;
основные факторы, повлиявшие на решение;
объяснение результата на естественном языке.
Примечание

Проект предназначен для учебных и исследовательских целей. Предсказания модели не следует использовать как единственный источник информации при принятии реальных кредитных решений.
